\# Sistema de Gestão de Notas



Projeto de demonstração de Integração Contínua (CI) com GitHub Actions.



\## Funcionalidades

\- Calcular média de três notas

\- Verificar situação (Aprovado/Reprovado)

\- Validar notas (0-20)
